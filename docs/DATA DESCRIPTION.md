A. Environmental Sensors (The Rooms)

Ambient Temperature & Humidity (General site climate)
Switch Room Temp (SWITCH MSC10)
Battery Room Temp (BAT MSC10)
Energy/Power Room Temp (ENR MSC 10)
Telecommunications Room Temp (V-SAT MSC10)
B. UPS & Power Telemetry (The Devices)

Grid Power Input: Input Voltage across 3 phases (L1, L2, L3) and Input Frequency (Hz).
UPS Output Power: Output Voltage, Output Current (Amps), and Output Load (%) across all 3 phases.
UPS Internal Health: Internal UPS Temperature (°C) and Battery Capacity Remaining (%).
C. System Events & Alarms (The Operations)

SCADA Alarms: Grid power failures ("Absence de Tension Reseau"), high-temperature alerts, and general SCADA hardware alerts.
UPS Alarms: General UPS faults, bypass modes, or battery warnings.
Climate System Logs: AC unit start/stops, faults, and admin logins.
